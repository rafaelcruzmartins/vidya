# Code of Conduct

We want this project to be welcoming, respectful, and useful for everyone.

## Our Standards

Examples of positive behavior:

- Be respectful and constructive
- Accept feedback professionally
- Help others learn
- Focus on what is best for the project
- Communicate clearly and kindly

Examples of unacceptable behavior:

- Harassment or abusive language
- Personal attacks
- Discrimination of any kind
- Trolling or deliberately disruptive behavior
- Sharing private information without permission

## Scope

This code of conduct applies to issues, pull requests, discussions, reviews, and other community spaces related to this project.

## Enforcement

Project maintainers may edit, remove, or reject comments, issues, pull requests, or contributions that do not follow this code of conduct.

## Reporting

If someone is violating this code of conduct, contact the maintainers privately through your organization contact channel or project email.

## Consequences

Depending on severity, maintainers may issue a warning, limit participation, or ban a contributor from the project spaces.
